## 1. 设计原则

1. **事实先于解读。** 排盘结果作为对话的依据展示：对话里有「已排盘」记录，侧栏列出星体位置，回复里引用的盘面事实用强调色标出。
2. **三步到对话。** 建档案 → 选咨询类型 → 对话。不设仪表盘、引导教程或设置中心。
3. **额度始终可见。** 顶栏显示本期用量，输入框下说明每条消息消耗 1 次；用尽时保留对话并给出升级入口，不弹窗打断。
4. **合规内容是界面的一部分。** AI 生成提示、免责声明、18 岁确认、亲友档案同意、导出与删除账号都在画板上，对应 LLD §8.1。
5. **延续旧前端的视觉。** 深色底、金色强调、Cinzel 字标取自 `../vela/frontend-v2/src/index.css`，不另起风格。

| 路径 | 形态 | 内容 | 对应能力（LLD §4） |
| --- | --- | --- | --- |
| `/`（含 `/consult*`、`/profiles`、`/account` 兼容） | 两栏单工作台 | 可折叠左边栏（`logo-small.webp` 点击折叠/展开、新建咨询、出生档案录入与合盘多选、历史咨询、底部 `⚙ 设置与订阅`）+ 极简主对话区（欢迎问候、流式对话与内联星盘数据卡、底部悬浮胶囊输入框 + `个人星盘 / 多人合盘` 模式切换）+ 按需滑出的 `✦ 星盘` 抽屉 | Firebase Auth、`previewNatalWheel`、`resolveLocation`、`createSession`、`chat`、Firestore、Stripe 扩展 |

不引入路由库，用 `location.pathname` 做分支；根节点保留 `ErrorBoundary` 渲染兜底。

## 3. 关键交互（Gemini 极简哲学与分级能力）

- **品牌 Logo 与折叠图标窄轨（点击 Logo 展开/收起）**：
  - 桌面端左侧栏折叠时保留 `80px` 图标窄轨（`logo-small.webp`、`+` 新咨询、`🔍` 搜索历史、`✦` 出生档案、底部 `订阅` 小按钮与用户头像），手机端收进左上角 Logo 抽屉按钮，去掉顶栏横线使整页背景统一。
  - 点击左上角 Logo 展开侧栏后，在完全对齐的位置展示完整 `logo-small.webp` + `VELA` 字标，右侧紧邻 `🔍` 搜索按钮与 `«` 折叠按钮。
- **Gemini 式居中欢迎、历史小窗与左下订阅/账号入口**：
  - 空白状态时，欢迎语「你好，想从哪颗星开始聊？」与悬浮胶囊输入框一同居中展示；尚无档案时输入框提示「点击左上角 Logo 添加出生信息」。
  - 侧栏不堆叠最近咨询列表，历史对话统一通过 `🔍` 按钮弹出居中搜索小窗浏览与检索；侧栏底部左侧放置小「订阅」按钮，下方展示登录用户头像与名称（点击查看账号与合规），移除独立 `⚙` 设置按钮。
- **出生信息录入、档案切换与合盘控制全在左边栏**：
  - 恢复「在左侧边栏录入与管理出生信息」的交互：未建档时点击左侧「+ 添加出生信息」就地展开表单（支持 `个人 / 公司 / 国家` 实体类型，城市搜索自动匹配经纬度与时区）。
  - **主对话区不放置任何出生表单与产品介绍卡片**，保持类似 Gemini 的极简空白画布与底部悬浮胶囊输入框；若尚无任何档案，输入框提示「请先在左侧边栏添加出生信息」。
- **两种咨询模式与三档订阅边界**：
  - 输入框左侧模式切换器仅保留 **`个人星盘`** 与 **`多人合盘`**：
    - `Free`（每月 3 次）：仅可使用「个人星盘」西洋本命盘；点击「多人合盘」引导升级。
    - `Go`（每月 60 次）：解锁「个人星盘」完整西洋占星（本命 + 行运）与 **2 人合盘**（限个人档案）。
    - `Pro`（每月 300 次）：解锁「个人星盘」西洋 + 八字 + 紫微交叉对比，以及 **最多 4 个档案的多人合盘**（支持个人、公司、国家盘）。
- **先排盘体验 → 首问统一登录建档**：
  - 未登录访客可在左侧边栏填写出生信息并即时在右侧 `✦ 星盘` 抽屉查看真实本命盘（仅调用 `previewNatalWheel`，本地草稿暂存）。
  - 首次点击「发送提问」时触发统一的「Google 登录 + 勾选已满 18 岁及服务条款/隐私政策」弹窗；授权成功后自动保存草稿档案、创建会话并接力流式回复，无需二次操作。
- **对话、思考动画、内联星盘卡与打印导出**：
  - 发送后先展示星光脉冲**思考动画**与分步状态（「正在计算星盘参数…」→「正在推演解读…」），首包到达后平滑流式输出。
  - 回复上方内联展示可折叠的**星盘数据卡**（`✓ 已排盘` + 展开查看完整星盘 SVG 与星体表），右上角支持**复制文本**与**打印 / 另存为 PDF**（`@media print` 隐藏侧栏与输入区）。
- **额度用尽（3 / 3 用完后）**：保留完整历史对话与星盘可读，底部输入框原地替换为「本月免费次数已用完」订阅升级面板（含下次 UTC 重置日期与 Go/Pro 升级按钮）。
- **统一设置与订阅（左边栏底部 `⚙` 齿轮）**：点击打开设置弹窗，整合「订阅与用量」「出生档案管理」「导出数据（JSON）」「输入『删除』二次确认删除账号」「退出登录」。

## 5. 可访问性

- 用真实的 `<button>`、`<a href>`、`<input>` 与 `<label>`，不在 `div` 上绑点击。
- 仅图标的按钮带 `aria-label`；装饰性 SVG 带 `aria-hidden`。
- 选中状态同时用边框和底色表达，不只靠颜色。
- 所有页面在手机宽度下可用，不出现横向滚动。

## 8. 占星师调校工作台（设计待实现）

对应 LLD §4.7。主要用户是没有代码基础的占星师，核心任务是选择星盘、调整解读方法、比较回答并交付认可的版本。工作台由本机服务提供，前端监听 `0.0.0.0:4310`，可通过主机局域网地址访问；后端经同源代理访问，浏览器草稿分别保存。由工程人员配置启动入口及模型连接；公开用户网站不包含该界面。Genkit UI 仅用于工程诊断。

### 8.1 页面布局与入口

沿用 §4 的字体、深色和金色变量，优先保证长文本编辑与阅读。桌面宽度 ≥1280px 时使用全宽工作区（本页覆盖 1200px 最大宽度）：左侧案例区 280px，中间编辑区与右侧预览区均不小于 400px，栏间距 16px，页面边距 24px。顶部固定操作栏，三栏内容各自滚动。

| 区域 | 内容与主要操作 |
| --- | --- |
| 顶部栏 | “Vela 解读工作台”、产品名称选择器、版本名称、保存状态、固定标签“本地草稿 · 尚未上线” |
| 运行操作 | “开始解读”为金色主按钮；运行时变为“停止”；“保存版本”“版本对比”“导出交付包”为次级按钮 |
| 左栏：测试案例 | 案例选择、档案列表与星盘缩略图、咨询问题、解读深度；“更多案例设置”收起历史消息、参考日期及盘面模式 |
| 中栏：解读设置 | 页签“角色与风格”“技法指南”“技法说明”“回答结构”“上下文模板”；每项显示名称、用途、来源版本及编辑状态 |
| 右栏：回答预览 | 默认渲染正文、星盘卡片与追问；“本次依据”页签查看实际使用的盘面事实、技法与指南 |
| 辅助入口 | “高级诊断”展开完整上下文、参数、原始文本、资源清单及 trace；普通流程无需使用 |

768–1279px 时折叠左栏为“测试案例”抽屉，编辑与预览分栏；低于 768px 使用“案例 / 设置 / 预览”单页签布局。对比在窄屏上下排列，标签始终标明基线和候选。长内容换行，避免全页横向滚动。

首次打开预选第一个可用产品与一份内置案例，预览显示“选择案例后点击开始解读”。连接未就绪时显示“模型连接尚未配置，请联系负责安装的同事”，禁用运行但允许编辑及保存，不向占星师索取 API Key 或命令。

### 8.2 测试星盘与问题

内置 A（北京）、B（纽约）、C（悉尼）、A/B 合盘、A 迁移伦敦案例，按 LLD §4.7.4 核验并迁移。每张案例卡显示名称、出生日期/时间、地点/时区、适用技法及是否为固定盘面；参考日期固定显示，用户可以明确修改。名称使用测试代号，不暗示真实客户身份。

“查看 / 编辑出生资料”打开普通表单；内置案例修改后保存为副本，原始基线保留。星盘组合受当前产品支持的档案数量与类型限制。不支持的技法或档案类型显示具体原因。缺失出生时间时不自动填 00:00，明确提示当前计算所需信息。

“实时排盘 / 使用固定盘面”用业务说明解释：前者用当前计算程序生成数据，后者保持数据一致以比较解读方法。切换会使已有结果标为旧结果；固定盘面缺少所需技法时给出更换案例或使用实时排盘操作。

问题使用普通多行输入框，可选择案例预置问题；历史以带“用户 / 顾问”标签的消息列表编辑。预览中的追问可作为新的测试问题载入，必须再次点击运行，不自动产生付费请求或修改基线。

### 8.3 编辑解读内容

所有可调文本使用带标签的普通文本编辑器，默认不显示 JSON。技法指南先选择技法名称，再编辑摘要与正文；技法说明用于调整模型如何理解已有排盘能力，不允许在此创建或授权工具。

模板变量通过“插入资料”菜单以中文名称选择，例如“出生资料”“已验证盘面事实”，显示为不可拆坏的变量标记；未知或缺失必需变量在字段旁提示，并阻止运行。保留用户消息角色边界，不通过模板将用户文字变成系统规则。

资源来源显示“本产品专用”或“与 N 个产品共用”。修改共享内容时默认形成当前产品副本；选择“更新共用内容”须展示受影响产品及确认操作，保存为新的共享版本。固定安全规则、参数结构和权限只读，说明“由系统维护”；允许查看完整生效文本。

“保存草稿”持久化当前编辑；“保存版本”填写版本名称与修改说明，生成不可变快照。编辑已有版本时产生新草稿。切换产品、案例或离开页面时如有未保存修改，提供“保存并继续 / 放弃修改 / 返回编辑”；恢复旧版本通过创建草稿实现，不覆盖历史版本。

### 8.4 运行、预览与依据

点击运行前就地检查必填项与配置；错误聚焦首个问题并保留所有输入。运行状态依次显示“准备资料”“计算星盘”“生成解读”“整理结果”，不展示模型内部思考内容，不伪造进度百分比。

运行绑定点击时的配置、星盘、问题和参考时间。运行中可继续编辑，但预览显示“本次结果对应运行前的设置”；再次运行需先停止或等待当前运行完成。重复点击不创建第二个请求。

预览复用用户端正文和星盘卡片渲染。生成中内容标为“生成中，尚未完成校验”，完成后切换为最终处理结果；提示被修正或删除的内容，可展开原因。本次依据仅展示可核查的盘面数据、调用步骤与指南，不将其称为模型思维过程；指南未被加载时明确标记“本次未使用”。

停止后保留已有文本并标记“不完整”；失败显示发生阶段和中文恢复建议，提供“重试”，重试需用户点击。结果底部展示耗时和估算费用，未知时显示“暂无法估算”。运行前说明模型调用会产生费用，停止仍可能产生已发生的费用。

### 8.5 版本对比与交付

“版本对比”展开双栏，左侧选择基线版本，右侧选择候选版本；两侧共用同一案例、问题、历史与参考时间。先展示文本配置差异，再由用户点击“运行对比”，分别显示运行状态和费用；一侧失败不清空另一侧。支持查看两份回答、依据和格式差异，不用文字差异自动判断质量。

占星师按“盘面事实准确 / 解读切题 / 表达清楚 / 技法合适”分别选择“通过 / 需修改 / 未评价”，并填写备注。改变案例或配置后，旧评价仍绑定旧运行，新结果重新评价。存在失败或未评价案例时明确列出，不伪称已通过。

“导出交付包”展示版本、修改说明、已测试案例与评价、未解决问题；导出完整配置快照与测试摘要供工程人员校验发布。默认不附带原始执行日志；界面提供单独的“导出诊断信息”，提示其中包含测试输入和输出。导出成功提示“已导出，请交由负责发布的同事处理”，不显示“上线成功”。

### 8.6 状态与验收

| 状态 | 界面反馈 |
| --- | --- |
| 未保存 / 保存失败 | 顶栏文字提示；失败保留编辑内容，提供重试 |
| 已保存 | 显示保存时间，重新打开恢复本地草稿 |
| 配置已改、结果过期 | 预览保留原结果及版本标签，提示重新运行 |
| 运行中 / 停止中 | 状态文字及停止按钮；停止中禁用重复操作 |
| 空结果 / 模型失败 | 可行动错误提示，保留输入与已有诊断 |
| 固定盘面缺失 | 指出缺少的技法，提供切换案例或实时排盘 |
| 产品配置不兼容 | 显示不支持的能力；阻止运行，允许查看与导出问题信息 |

沿用 §5 可访问性：表单标签、键盘操作、弹窗焦点管理、运行状态使用非打断式播报；状态同时用文字表示。对比两栏有明确标题，不能仅靠颜色区分。
