# Vela CF — UI/UX 设计记录

> 画布（可点击原型）：https://claude.ai/artifact/Cknr5hhG8YGLzkqEvAvf2T（私有，需项目负责人在 Share 菜单分享后才能打开）
>
> 画板源码：`docs/design/*.dc.html`。这是画布格式，不能直接在浏览器运行，用途是查阅确切的标记、间距和颜色。
>
> 实现范围以本文件为准。既有用户页面以画板为依据；§8 是占星师工作台新增页面与状态的文字设计依据，尚未制作可点击画板。要加未定义的页面、状态和控件，先改设计再改代码。

## 1. 设计原则

1. **事实先于解读。** 排盘结果作为对话的依据展示：对话里有「已排盘」记录，侧栏列出星体位置，回复里引用的盘面事实用强调色标出。
2. **三步到对话。** 建档案 → 选咨询类型 → 对话。不设仪表盘、引导教程或设置中心。
3. **额度始终可见。** 顶栏显示本期用量，输入框下说明每条消息消耗 1 次；用尽时保留对话并给出升级入口，不弹窗打断。
4. **合规内容是界面的一部分。** AI 生成提示、免责声明、18 岁确认、亲友档案同意、导出与删除账号都在画板上，对应 LLD §8.1。
5. **延续旧前端的视觉。** 深色底、金色强调、Cinzel 字标取自 `../vela/frontend-v2/src/index.css`，不另起风格。

## 2. 页面与工作台结构（纯 Gemini 式两栏单工作台）

| 路径 | 形态 | 内容 | 对应能力（LLD §4） |
| --- | --- | --- | --- |
| `/`（含 `/consult*`、`/profiles`、`/account` 兼容） | 两栏单工作台 | 可折叠左边栏（`logo-small.webp` 点击折叠/展开、新建咨询、出生档案录入与合盘多选、历史咨询、底部 `⚙ 设置与订阅`）+ 极简主对话区（欢迎问候、流式对话与内联星盘数据卡、底部悬浮胶囊输入框 + `个人星盘 / 多人合盘` 模式切换）+ 按需滑出的 `✦ 星盘` 抽屉 | Firebase Auth、`previewNatalWheel`、`resolveLocation`、`createSession`、`chat`、Firestore、Stripe 扩展 |
| `/privacy`、`/terms` | 静态文本页 | 隐私政策与服务条款，沿用深色排版，支持从首页/登录弹窗直达 | 静态页 |

不引入路由库，用 `location.pathname` 做分支；根节点保留 `ErrorBoundary` 渲染兜底。

## 3. 关键交互（Gemini 极简哲学与分级能力）

- **品牌 Logo 与折叠图标窄轨（点击 Logo 展开/收起）**：
  - 桌面端左侧栏折叠时保留 `80px` 图标窄轨（`logo-small.webp`、`+` 新咨询、`🔍` 搜索历史、`✦` 出生档案、底部 `订阅` 小按钮与用户头像），手机端收进左上角 Logo 抽屉按钮，去掉顶栏横线使整页背景统一。
  - 点击左上角 Logo 展开侧栏后，在完全对齐的位置展示完整 `logo-small.webp` + `VELA` 字标，右侧紧邻 `🔍` 搜索按钮与 `«` 折叠按钮。
- **Gemini 式居中欢迎、历史小窗与左下订阅/账号入口**：
  - 空白状态时，欢迎语与输入框居中；尚无档案时显示「添加出生信息，查看星盘」主按钮，直接打开已有建档表单。保存成功返回对话并聚焦输入框，等待档案同步完成后再聚焦。
  - 侧栏不堆叠最近咨询列表，历史对话统一通过 `🔍` 按钮弹出居中搜索小窗浏览与检索；侧栏底部左侧放置小「订阅」按钮，下方展示登录用户头像与名称（点击查看账号与合规），移除独立 `⚙` 设置按钮。
  - 展开侧栏只突出「新咨询」与当前档案，其余入口采用紧凑单行列表；额度信息保持可见，说明文字按需展示。
- **出生信息录入、档案切换与合盘控制全在左边栏**：
  - 恢复「在左侧边栏录入与管理出生信息」的交互：未建档时点击左侧「+ 添加出生信息」就地展开表单（支持 `个人 / 公司 / 国家` 实体类型，城市搜索自动匹配经纬度与时区）。
  - **主对话区不放置出生表单与产品介绍卡片**；首次使用只提供建档入口，沿用已有档案管理表单。
  - 输入区不放档案切换控件，统一使用左侧栏的主档案与合盘勾选；手机通过左上角侧栏抽屉操作。历史咨询显示创建时绑定的对象与模式；切换对象开启新咨询，原对话留在历史记录中。
  - 输入区采用上下两行：上方为完整宽度的文字输入，下方为推演深度与发送/停止按钮。咨询文字区聚焦时不显示内层金色描边，焦点以外围输入区的中性色边框提示，高对比度模式保留系统描边。手机端深度选择使用原生下拉框，桌面保留三档按钮；控件保持 44px 操作尺寸，并在 320px 宽度下可用。
  - 新建档案的出生日期时间留空；「搜索城市」选中后显示地点、经纬度和时区供核对。保存成功返回对话，并显示简短的就地成功提示。
- **两种咨询模式与三档订阅边界**：
  - 左侧栏的档案选择支持 **`个人星盘`** 与 **`多人合盘`**：
    - `Free`（每月 3 次）：仅可使用「个人星盘」西洋本命盘；点击「多人合盘」引导升级。
    - `Go`（每月 60 次）：解锁「个人星盘」完整西洋占星（本命 + 行运）与 **2 人合盘**（限个人档案）。
    - `Pro`（每月 300 次）：解锁「个人星盘」西洋 + 八字 + 紫微交叉对比，以及 **最多 4 个档案的多人合盘**（支持个人、公司、国家盘）。
- **先排盘体验 → 首问统一登录建档**：
  - 未登录访客可在左侧边栏填写出生信息并即时在右侧 `✦ 星盘` 抽屉查看真实本命盘（仅调用 `previewNatalWheel`，本地草稿暂存）。
  - 首次点击「发送提问」时打开登录弹窗，Google、邮箱密码和免密邮件登录入口不以条款勾选为前置条件。身份验证后通过 API 读取既有确认记录；已有 acceptedTermsAt / confirmedAdultAt 的账户直接继续，不重复确认或改写时间戳。仅新账户或缺少确认记录时显示一次「首次使用，完成账号确认」，明确勾选后才能初始化应用账号、保存草稿和开始解读；普通登录不自动替用户同意。登录与首次确认完成后接力原问题。
- **对话、思考动画、内联星盘卡与打印导出**：
  - 发送后先展示星光脉冲**思考动画**与分步状态（「正在计算星盘参数…」→「正在推演解读…」），首包到达后平滑流式输出。
  - 回复上方内联展示可折叠的**星盘数据卡**（`✓ 已排盘` + 展开查看完整星盘 SVG 与星体表），右上角支持**复制文本**与**打印 / 另存为 PDF**（`@media print` 隐藏侧栏与输入区）。
  - 阅读上文时显示「回到最新回复 ↓」，点击恢复自动跟随；生成中、主动停止和生成失败分别显示明确状态，不弹窗提示。
  - AI 正文支持 CommonMark 与 GFM：标题、强调、嵌套列表、表格、引用、链接、删除线、任务列表及代码块。流式片段逐次解析，未闭合内容保持可读，语法完整后显示对应格式；复制保留原始 Markdown。表格和代码块在自身区域横向滚动，手机页面不被撑宽。禁用原始 HTML，仅允许 HTTP(S)、邮件和相对链接；外部链接另开窗口，模型输出的图片仅显示替代文字。
  - 画像恢复原有居中标题、大幅人物插画与雷达图并列、三张核心星座卡、星座能量与主导行星双栏、洞察卡和日期天象区的完整排版；手机纵向排列，信息不折叠。保留统计及权重口径，辅助文字至少 13px；打开画像时默认选中档案所在地时区的今天并加载天象盘，切换日期后重新计算；日历与天象盘在桌面等宽并列，手机上下排列，盘面随栏宽缩放。海报保留原有插画、三核心星座、雷达与分布、底部二维码分区，原趋势区域展示真实本命元素分布。
- **额度用尽（3 / 3 用完后）**：仅应用明确返回 `QUOTA_EXCEEDED` 时判为月度额度不足；模型服务的 `resource-exhausted` 单独提示繁忙或受限，不修改本地额度。无限额度账号可超出档位预算继续发送。保留完整历史对话与星盘可读，底部输入框原地替换为「本月免费次数已用完」订阅升级面板（含下次 UTC 重置日期与 Go/Pro 升级按钮）。
- **统一设置与订阅（左边栏底部 `⚙` 齿轮）**：点击打开设置弹窗，整合「订阅与用量」「出生档案管理」「导出数据（JSON）」「输入『删除』二次确认删除账号」「退出登录」。
- **内部开发者接入**：账号与合规弹窗内按服务端 capability 显示折叠区域，沿用现有面板、表单与按钮样式，不新增设置中心。用户选择权限、期限与档案后用当前账户重新验证身份；一次性 Token 仅当前界面展示和复制，关闭即清除。默认未开放用户隐藏，已有凭据的用户保留撤销入口。原生 label/fieldset、明确错误提示、44px 操作目标及 320px 窄屏布局必须可用；具体授权与状态见 LLD §11.11.9。

浏览器标签页使用 `/assets/logo-small.webp` 作为 Vela favicon。

## 5. 可访问性

- 用真实的 `<button>`、`<a href>`、`<input>` 与 `<label>`，不在 `div` 上绑点击。
- 仅图标的按钮带 `aria-label`；装饰性 SVG 带 `aria-hidden`。
- 选中状态同时用边框和底色表达，不只靠颜色。
- 所有页面在手机宽度下可用，不出现横向滚动。
- 弹窗与手机抽屉用原生 `dialog.showModal()`，支持 Escape、焦点约束及关闭后返回触发控件；操作目标至少 44px，表单使用关联标签。
- 切换会话、退出登录时取消旧回复，过期响应不能覆盖当前页面；发送失败保留可重试输入，主动停止保留已生成内容。阅读上文时不自动滚到底部。
- 画像保留日期选择及指定日期当地 12:00 的真实天象盘；移除无实际计算依据的能量分数、月相标签和海报运势趋势。

## 7. 不做

Admin 界面、深浅色切换、多语言切换、引导教程、通知中心、消息搜索、会话重命名、分享与导出图片、头像上传、自定义主题、动效库、骨架屏之外的加载动画。

以上为公开用户产品的范围；本地占星师工作台按 §8 实施。

## 8. 占星师调优入口

采用 [LLD](LLD.md) §4.7 的私有 Prompt 目录、个人 harness 与本地 MCP。占星师用自然语言选择合成案例、提出解读改法、比较回答与依据，再提交候选；GitHub 文件页展示文本与报告。连接和安装方式见调优包 README。

2026-11-15 按负责人要求移除旧 Playground 页面、专用 HTTP 服务和启动脚本。网页产品不再包含旧编辑工作台，调优通过 MCP 进行。浏览器旧 localStorage 草稿未自动迁移，也未主动清除；生成代码、合成案例与历史评测证据保留。无代码占星师的实际 harness 使用验收仍需完成。
