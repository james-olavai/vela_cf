# Vela 调优仓库协作说明

本仓库用于调整占星咨询文本。先读 README.md 的安装连接说明；涉及 Prompt 修改、案例测试或回答比较时，读取 `.agents/skills/vela-prompt-tuning/SKILL.md`。不支持自动发现 skill 的 harness 也应直接读取该文件。

## 工作范围

- `prompts/` 是可调文本源：产品角色、共享咨询规范、技法指南与工具说明。读取 `prompts/manifest.json` 确认资源与产品关系，修改共享内容时说明影响产品。
- `runtime/`、`runtime.lock.json`、依赖锁、校验和及 `cases/` 是固定执行基准。通常只改 Prompt 和脱敏报告；新增能力、模型适配、案例或运行时升级属于单独的工程变更，不能用改校验和绕过兼容检查。
- `npm ci` 安装固定依赖；`npm run setup` 生成当前电脑的 `.vela/mcp.config.json`；`npm run verify` 检查运行时完整性。移动目录后重新 setup。
- `.env`、`.vela/`、原始 trace 和个人资料只留本机，不提交。凭据配置进程环境或 `.env`；不要读取/打印令牌来排障。

## 评测约定

harness 可以用自己的模型提出改法；正式回答必须经 Vela MCP 调用被测模型。不要以 harness 自己模拟星盘咨询冒充真实评测。当前运行时仅适配 Hydrogen 网关，生产调用条件和本地预算可能不同。

MCP 未连接时说明缺失的接入步骤。没有实际运行就报告“未验证”；不要伪造工具调用、用量、模型型号、回答或通过结论。

质量目标是直答核心问题、客观中立、说明有依据的盲区、普通语言及自主安全的积极引导。盘面不能证明他人动机、现实因果或未来必然事件；不通过文风优化掩盖排盘算法错误。

保存可追溯候选与脱敏报告，区分本地修改、已提交、已合并和已部署。用户授权提交/推送时只提交本次相关文件；生产发布由产品维护者执行，合并本仓库不自动上线。
